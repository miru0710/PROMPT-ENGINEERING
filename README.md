2. Transformer Architecture
The Transformer is a deep learning architecture introduced in the research paper Attention Is All You Need in 2017. It was developed to process sequential data, particularly natural language, using an attention mechanism instead of relying entirely on traditional recurrent neural networks.

Transformers can understand relationships between words, even when they are located far apart in a sentence. They are widely used in language translation, text generation, summarisation, and conversational AI.

Examples:
- GPT models
- Google Gemini
- BERT

2.1 Structure of Transformer Architecture
The original Transformer architecture consists of two major components:
1. Encoder: Processes the input sequence and creates meaningful representations of the input.
2. Decoder: Uses the encoded information and previously generated tokens to produce the output sequence.
The encoder and decoder contain multiple layers of attention and feed-forward neural networks.

2.2 Encoder Component
The encoder receives the input sequence and converts it into meaningful numerical representations.

Its main functions include:
- Input Embedding: Converts input words or tokens into numerical vectors that the model can process.
- Positional Encoding: Adds information about the position of each token in the sequence because the Transformer does not process words in a fixed sequential order.
- Multi-Head Self-Attention: Identifies relationships between different words in the input sequence.
- Feed-Forward Neural Network: Processes the attention outputs to learn more complex patterns.
- Add and Normalize: Uses residual connections and layer normalisation to improve training stability.
Example: For the sentence "Artificial Intelligence changes the world", the encoder processes the words and identifies their relationships to understand the overall context.
2.3 Decoder Component
The decoder generates the output sequence using the information received from the encoder and previously generated tokens.

Its important components are:
- Masked Multi-Head Self-Attention: Allows the decoder to consider previously generated tokens while preventing it from accessing future tokens.
- Encoder-Decoder Attention: Allows the decoder to focus on relevant information from the encoder output.
- Feed-Forward Neural Network: Processes the information and helps generate the next token.
- Output Linear Layer and Softmax: Converts the decoder output into probabilities for possible next tokens.
Example: When translating "Good Morning" into another language, the decoder generates the translated words based on the encoded input representation.

Note: Some modern Transformer models, such as GPT, use a decoder-only architecture, while BERT uses an encoder-only architecture.
3. Attention Mechanism
The attention mechanism is one of the most important features of Transformer architecture. It helps the model identify which words or tokens are more important when processing a particular word.

Instead of treating every word equally, attention assigns different importance to different parts of the input sequence.
3.1 Working of Attention Mechanism
The attention mechanism uses three important elements:
1. Query (Q): Represents the information that a token is looking for.
2. Key (K): Represents the information available from other tokens.
3. Value (V): Contains the actual information that is used to produce the attention output.
The model compares queries with keys to calculate attention scores. These scores are converted into weights using the Softmax function. The weights are then applied to the value vectors to produce the final output.

The scaled dot-product attention formula is:
\[
Attention(Q,K,V)=Softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V
\]

Where:
- Q represents Query.
- K represents Key.
- V represents Value.
- \(d_k\) represents the dimension of the key vectors.

3.2 Types of Attention
1. Self-Attention

Self-attention allows each word in a sequence to focus on other words within the same sequence. It helps the model understand contextual relationships.

2. Multi-Head Attention

Multi-head attention uses multiple attention mechanisms called heads simultaneously. Each head learns different relationships between words, improving the model's ability to understand complex information.

3. Masked Self-Attention

Masked self-attention prevents the decoder from looking at future tokens during generation. This ensures that the model generates content in the correct order.

Example: In the sentence "The student placed the book on the table because it was heavy", attention helps the model understand the relationship between the word "it" and the relevant object in the sentence.
4. Process of Generating Outputs in Transformers
Transformers generate outputs through a sequence of operations.

Step 1: Input Prompt

The user provides an instruction or prompt to the AI system.

Example: "Explain Artificial Intelligence."

Step 2: Tokenisation

The input sentence is divided into smaller units called tokens. These may represent words, parts of words, or punctuation marks.

Step 3: Embedding

The tokens are converted into numerical vectors called embeddings.

Step 4: Positional Encoding

Position information is added to the token representations so that the model can understand the order of the tokens.

Step 5: Attention Processing

The attention mechanism identifies relationships between tokens and determines which information is important.

Step 6: Neural Network Processing

The processed information passes through feed-forward neural network layers to learn complex patterns and relationships.

Step 7: Probability Calculation

The model calculates probabilities for possible next tokens using its output layer and Softmax function.

Step 8: Token Generation

The model selects the next token based on its probability distribution and the chosen generation strategy.

Step 9: Repeated Generation

The generated token is added to the sequence, and the process repeats until the required output is completed or a stopping condition is reached.

Example: When a user enters "Artificial Intelligence is", a language model may predict the next token as "a", followed by "technology", and continue generating a meaningful sentence.

1. The Transformer Architecture
Introduced in 2017 by Vaswani et al. in the paper "Attention Is All You Need," the Transformer architecture revolutionized AI by discarding sequential processing (used by older Recurrent Neural Networks) in favor of parallelized computation and context-mapping.
The Attention Mechanism
The core breakthrough of the Transformer is the self-attention mechanism, which allows the model to evaluate the relationship and relative importance of every token (word, sub-word, or pixel) in a sequence simultaneously, regardless of its distance from other tokens.
Queries (Q), Keys (K), and Values (V): Inspired by information retrieval systems, each token in the input sequence is projected into three vectors: a Query, a Key, and a Value.

Calculating Attention: The model computes a dot product between the Query of a given token and the Keys of all other tokens to determine an "attention score." These scores are scaled, normalized using a softmax function, and multiplied by the Value vectors to produce a context-aware representation.

Multi-Head Attention: Instead of performing a single attention calculation, the architecture uses "multiple heads" running in parallel. This allows the model to focus on different aspects of text simultaneously (e.g., one head tracks grammatical syntax, while another tracks pronouns and semantic intent).
Encoder and Decoder Components
The original Transformer follows an Encoder-Decoder structure, though many modern models utilize only one of these components depending on the task:

The Encoder: Processes the input sequence, ingests it, and transforms it into a deep, contextualized numerical representation (embeddings). It is widely used in models focused on understanding and analysis (e.g., BERT).

The Decoder: Takes the encoded context (or generates text autonomously in decoder-only models) and iteratively predicts subsequent tokens. It features masked self-attention to prevent the model from "looking ahead" at words it has not yet generated.
Positional Encoding
Because Transformers process all tokens in parallel rather than sequentially, they inherently lack a sense of word order (e.g., "Cat eats fish" vs. "Fish eats cat" would look identical to pure attention layers). To solve this, Positional Encodings are added to the input embeddings to inject mathematical markers representing each token's position in the sequence.

The Process of Generating Outputs
Transformers typically function as autoregressive models during text generation:

Tokenization: The input prompt is broken down into tokens and converted into numerical vectors, combined with positional encodings.

Forward Pass: The tokens pass through multiple layers of multi-head attention and feed-forward neural networks.

Next-Token Prediction: At the final layer, the model outputs a probability distribution over its entire vocabulary for the very next token.

Sampling and Iteration: A token is selected from this distribution (using strategies like temperature scaling or top-p sampling). This newly generated token is then appended to the input sequence, and the process repeats iteratively until an end-of-sequence token is reached.

Example: OpenAI's GPT series, Google Gemini, and Anthropic Claude use decoder-only Transformer architectures to generate human-like text, code, and structured analysis.
2. Generative Adversarial Networks (GANs)
Introduced by Ian Goodfellow in 2014, GANs utilize a game-theoretic approach involving two neural networks competing against one another in a zero-sum game.
Structure and Working Principles
The Generator: Acts like a counterfeiter. It takes random noise as input and attempts to synthesize realistic data (such as fake images, audio, or text) that mimics the training distribution.  
The Discriminator: Acts like a detective or art expert. It receives a mix of real data (from the training set) and fake data (from the generator) and evaluates every sample, outputting a probability score indicating whether the data is real or generated.   
The Training Loop
During training, the generator tries to fool the discriminator, while the discriminator gets better at catching fakes. This dynamic back-and-forth forces both networks to continuously improve. Ideally, the training reaches a Nash equilibrium where the generator creates data so hyper-realistic that the discriminator can no longer tell the difference.
Advantages & Limitations: GANs are renowned for producing exceptionally sharp, high-resolution images. However, they are notoriously unstable to train and can suffer from mode collapse, a failure state where the generator learns to produce only a single, repetitive type of output that tricks the discriminator.  
Relevant Examples: Deepfake video generation, AI-generated human faces (e.g., This Person Does Not Exist), and high-end image style transfer.   
3. Variational Autoencoders (VAEs)
VAEs are probabilistic graphical models rooted in Bayesian inference. Unlike standard autoencoders designed strictly for data compression, VAEs are built to generate new data by modeling an explicit probability distribution.  
Structure and Working Principles
The Encoder: Compresses high-dimensional input data (e.g., an image) into a lower-dimensional latent space. Instead of mapping inputs to fixed points, a VAE encoder maps them to a probability distribution defined by a mean and a variance.  
The Latent Space: A continuous, compressed mathematical space where similar data points cluster together. Because it is probabilistic and smooth, researchers can sample random points from this space to generate entirely new variations.   
The Decoder: Takes a sampled point from the latent space and reconstructs it back into high-dimensional data (e.g., generating a new image or file).
Advantages & Limitations
VAEs offer stable training routines and structured, interpretable latent spaces, making them ideal for tasks requiring uncertainty estimation. 
Their primary drawback is that reconstructed or generated outputs tend to be blurry compared to the hyper-sharp results produced by GANs or diffusion models, because VAEs optimize pixel-level average error metrics.   
Relevant Examples: Snapchat/Instagram AR face filters, anomaly and fraud detection in financial transactions, and early molecular generation pipelines for drug discovery.
